# Vehicle assets

Kenney Car Kit (3D), Kenney — **CC0 1.0 Universal**.
Official asset and license listing: https://kenney.nl/assets/car-kit
License: https://creativecommons.org/publicdomain/zero/1.0/

Bundled Kenney model files:
`compact.glb`, `sedan.glb`, `sport.glb`, `police.glb`, `van.glb`, `pickup.glb`, `tractor.glb`, `taxi.glb`, `ambulance.glb`, `firetruck.glb`, `garbage-truck.glb`, `delivery.glb`, `suv.glb`, `suv-luxury.glb`, `race.glb`, `race-future.glb`, `kart-ooli.glb`, `tractor-shovel.glb`.
Some bundled files are retained as spare art; not every file defines a vehicle class.

Copies from:
- https://github.com/grvermeulen/H3-Teamy/tree/image/public/arena/cars
- https://github.com/Arslan12216775/kenney_car-kit/tree/master/Models/GLB%20format

Client modifications: per-class scale and rotation, paint on separate-paint models, wheel-node animation, supplemental lamps, day/night emissive lighting and body suspension. Textured models retain their original colormap.

**`bus.glb` is original project art**, deterministically generated by `tools/create-bus.mjs` and covered by the root MIT license. The city bus is not attributed to Kenney.

**Motorbike** is original procedural geometry in `public/models3d.js` (MIT), not a Kenney asset.

`manifest.json` is development metadata, regenerated with `npm run assets`; the runtime's explicit model map is in `public/models3d.js`.
